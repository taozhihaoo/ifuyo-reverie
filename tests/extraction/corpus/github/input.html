tinylog

A 200-line structured logger for Node.js. No dependencies, no configuration, JSON lines out of the box.

Install

npm install tinylog

Usage

import { log } from 'tinylog'
log.info('server started', { port: 3000 })
log.error('db unreachable', { host })

Features

  • JSON lines to stdout
  • child loggers with bound fields
  • level filtering via LOG_LEVEL
