Async Patterns I Actually Use

After ten years of JavaScript, these are the four async patterns that survived every framework change.

1. Promise gate

let gate
function once(fn) {
  gate = fn().catch(e => { gate = null; throw e })
  return gate
}

The gate reopens on failure, which is the whole trick.

2. Bounded pool

async function pool(items, worker, size = 4) {
  const queue = [...items]
  const runners = Array.from({ length: size }, async () => {
    while (queue.length) await worker(queue.shift())
  })
  await Promise.all(runners)
}

3. Deadline race

const result = await Promise.race([
  fetchJson(url),
  sleep(3000).then(() => { throw new Error('timeout') })
])

Deadlines belong to the caller, not the transport.

4. Cancel-safe loop

for await (const evt of events()) {
  if (cancelled) break
  handle(evt)
}

Everything else was fashion. These four were architecture.
