Configuration Reference

WidgetKit reads configuration from widget.config.json at project root. Unknown keys are ignored; missing keys fall back to defaults.

Core options

  • port — TCP port for the dev server (default 4173)
  • watch — enable file watching (default true)
  • logLevel — one of debug, info, warn, error

Example

{
  "port": 8080,
  "watch": false,
  "logLevel": "warn"
}

Changes take effect after restart. The watcher debounces writes by 120 ms.
