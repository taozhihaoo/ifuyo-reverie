# EPUB Export — ifuyo Reverie（M9）

> 把阅读资料可靠地带出 Reverie。使用说明与行为边界；架构见 docs/M9-STATUS.md。

## 导出入口

| 入口 | 行为 |
|---|---|
| 阅读器 →「导出 EPUB」 | 当前文章 → 单篇 EPUB（含图片） |
| 库视图 →「导出 EPUB（N 篇合并）」 | 当前视图全部文章 → 合并成一本书（题名页 + 目录 + 各文章一章 + 标注与笔记附录） |

导出前选择目标文件夹；文件名默认书名（非法字符自动替换）。导出完成在顶部提示区
显示路径与章节/警告/跳过数量；失败显示可读原因。

## 产物

- **标准 EPUB 3**：mimetype（STORE 首 entry）、container.xml、OPF、nav.xhtml、
  分章 XHTML、Reverie 阅读友好 CSS、内容寻址图片（`images/<sha256>.<ext>`，跨章去重）。
- **自包含**：不依赖网络即可阅读；图片已本地化嵌入；脚本/iframe/表单一律不携带
  （EPUB = 被动阅读产物）。
- **确定性**：同一份资料+相同选项重复导出，identifier/章节顺序/内容完全一致
  （`dcterms:modified` 为规范要求的导出时刻字段，随导出时间变化）。
- **元数据**：title/creator/language/identifier/日期/source（原始 URL 保留在元数据与
  章节来源行，不伪装作者身份）。
- **标注附录**（可选，默认在库视图合并导出中开启）：引文 + 笔记 + 日期 + 来源题名；
  按已保存内容导出，不重定位、不修改原文。

## 安全与可靠性

- 导出**只读**库文件——article.md/meta.json/annotations.jsonl/原始 PDF/EPUB 一律不改
  （测试断言字节级不变）。
- 原子写出：`<名字>.epub.<时间戳>.tmp` → 校验（含用 M6 阅读器真实回读）→ 原子改名；
  失败/取消自动清理临时文件，已存在的同名文件绝不被半成品覆盖。
- 取消：所有阶段响应取消；不留半个 EPUB。
- 部分失败：个别文档读取失败 → 跳过并在报告中列出；结构性失败 → 整体失败且不产损坏文件。
- Web→EPUB 的联网只发生在"采集新网页"一步（复用 M1 采集管线与 SSRF 防线）；
  已入库文章的导出**零网络**。

## 边界

- 表格暂不导出（记录 warning）；代码块逐字保留。
- OCR / DRM / Paywall 绕过 / PDF→EPUB：明确不支持。
- 导出不改变阅读进度、不标记已读、不产生标注/书签。
